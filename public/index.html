PostgreSQL Backup & Restore

            
Snapshot active database state or restore from an existing SQL script.

          

          
        

        

          
          

            

              CLI Utilities Status
            

            

          


          
          

            

              
Create Database Backup

              
Generate a complete snapshot of the active PostgreSQL schema and records.

            

            

              
              

                

                  

                    Plain SQL
                    .sql
                  

                  

                    Human-readable SQL script with standard DDL and DML statements. Best for auditing, version control, or restoring via psql and query tools.
                  

                

                
              


              
              

                

                  

                    Custom Format
                    .dump
                  

                  

                    PostgreSQL-specific compressed binary archive intended for pg_restore. Supports selective table recovery, schema reordering, and parallel restoration.
                  

                

                
              

            

          


          
          

            

              
Restore Database from SQL Script

              
Execute an existing .sql script against the active database.

            


            

              

                
                Destructive Action Notice
              

              

                Restoring executes real DDL and DML statements against the active database. Existing tables and records may be modified, truncated, or permanently overwritten. Always take a fresh backup before restoring.
